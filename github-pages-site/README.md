# Premalaya Social Development Society - GitHub Pages Site

This is the static website version of the Premalaya Social Development Society website, converted from Laravel to be hosted on GitHub Pages.

## About

Premalaya Social Development Society is dedicated to serving the community through various social development programs including:

- Children Ministry
- Women Ministry  
- Educational Support
- Health Care
- Medical Camps
- Relief Work
- Library Services

## Website Structure

- `index.html` - Home page with image carousel and program overview
- `about.html` - About us page with organization information
- `vision.html` - Our vision statement
- `mission.html` - Our mission statement
- `pastor.html` - Pastor information
- `shankar.html` - Shankar profile
- `savithribai.html` - Savithribai profile
- `contact.html` - Contact information
- `support.html` - Support and donation information
- Program pages: `children.html`, `women.html`, `education.html`, `health.html`, `medical.html`, `relief.html`, `library.html`

## Assets

- `css/` - Stylesheets including Bootstrap and custom styles
- `js/` - JavaScript files including jQuery, Bootstrap, and carousel plugins
- `img/` - Images organized by categories

## Deployment

To deploy this site on GitHub Pages:

1. Create a new GitHub repository
2. Upload all files to the repository
3. Enable GitHub Pages in repository settings
4. Select the main branch as the source
5. Your site will be available at `https://username.github.io/repository-name`

## Technologies Used

- HTML5
- CSS3 (Bootstrap 3.3.7)
- JavaScript (jQuery)
- Font Awesome 4.5.0
- Owl Carousel
- Swiper

## Original Project

This static site was converted from a Laravel 5.4 application to be compatible with GitHub Pages static hosting.
